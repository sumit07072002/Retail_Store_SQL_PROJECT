# SQL_PROJECTS

🛒 Retail Sales Data Cleaning & Business Analysis using SQL
📌 Project Overview

This project demonstrates a complete SQL-based data cleaning and business analysis workflow on a retail sales dataset. The objective was to prepare raw transactional data for analysis by resolving common data quality issues and then generate actionable business insights using SQL queries.

The project covers the complete data preparation process—from handling duplicate records and missing values to correcting inconsistent pricing and cleaning date formats—followed by solving real-world business problems using SQL.

🎯 Objectives
Clean and prepare raw retail data for analysis.
Improve data quality by removing inconsistencies.
Perform business analysis using SQL.
Generate insights that can support business decision-making.

🔧 Data Cleaning Tasks

✅ Removed Duplicate Records
Identified duplicate transaction records.
Created a new table containing only unique records.
Replaced the original table with the cleaned version.
✅ Fixed Missing Values
Identified NULL values across all columns.
Replaced missing customer locations with "Unknown".
Renamed corrupted column names created during CSV import.
✅ Corrected Incorrect Product Prices
Compared product prices between the Sales Transaction and Product Inventory tables.
Identified pricing mismatches.
Updated incorrect transaction prices using inventory data.
✅ Cleaned Date Format
Converted transaction dates stored as text into proper SQL DATE format.
Created a cleaned version of the table with standardized date values.
